# JustDo

Simple Tasks. Clear Mind.

JustDo is a lightweight task manager built with pure HTML, CSS and JavaScript.

The goal of this project is to provide a simple and distraction-free task manager with a clean interface and practical functionality.

---

## Features

- 📅 Calendar with month navigation
- ✅ Create tasks for any date
- ✏️ Edit existing tasks
- ❌ Delete tasks
- ☑️ Mark tasks as completed
- 📊 Task statistics
- 💾 Automatic saving with Local Storage
- 🔄 Completed tasks are displayed at the bottom of the list

---

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage API
